## ✨ תכונות עיקריות

### ניהול מתכונים
- **CRUD מלא** — יצירה, קריאה, עדכון ומחיקה של מתכונים
- **חיפוש חופשי** תוך כדי הקלדה — לפי שם מתכון *או* לפי מרכיב, עם debounce וביטול בקשות מיושנות
- **עימוד מצטבר** ("טען עוד") במקום טעינת כל המתכונים בבת אחת
- **"המתכונים שלי"** — עמוד אישי המסונן לפי המשתמש המחובר

### אימות והרשאות
- הרשמה והתחברות עם **JWT** (תוקף 30 יום)
- סיסמאות מוצפנות עם **bcrypt** ולעולם לא מוחזרות ללקוח
- **הרשאות ברמת משאב** — רק יוצר המתכון (או אדמין) יכול לערוך ולמחוק אותו
- זיהוי אוטומטי של טוקן שפג תוקף, עם הפניה חלקה למסך ההתחברות

### יצירת מתכונים עם AI 🤖
- יצירת מתכון מלא מתיאור חופשי בשפה טבעית (*"ארוחת ערב טבעונית מהירה"*)
- **עריכה בשיחה** — *"תעשה את זה חריף יותר"*, *"בלי מוצרי חלב"* — וה-AI מעדכן את המתכון כולו
- יצירת תמונת מזון למתכון, עם **נפילה אוטומטית** לתצלום אמיתי מ-TheMealDB אם יצירת התמונה לא זמינה
- שמירת הטיוטה ב-`sessionStorage` — מתכון שנוצר לא נאבד גם אם המשתמש עובר להתחבר באמצע

### חוויית משתמש
- **RTL מלא** עם Tailwind logical properties (`ps-`/`pe-`/`start-`)
- עיצוב רספונסיבי מלא, כולל תפריט המבורגר במובייל
- שלדי טעינה (skeletons) במקום מסכים ריקים
- `ErrorBoundary` גלובלי — שגיאת רינדור מציגה מסך הסבר, לא דף לבן
- דף 404 מעוצב, תמיכה ב-`prefers-reduced-motion`, ותגי "✨ AI" למתכונים שנוצרו אוטומטית

## 📁 מבנה הפרויקט

```
.
├── backend/                 # שרת Node.js + Express
│   ├── config/               # חיבור DB, ולידציית env, לקוח Gemini
│   ├── middleware/           # אימות (protect/optionalAuth/admin), rate limiting
│   ├── models/               # סכמות Mongoose (User, Recipe)
│   ├── routes/               # authRoutes, recipeRoutes, aiRecipes
│   ├── utils/                # יצירת טוקנים, ניקוי תמונות יתומות
│   ├── scripts/              # סקריפטי תחזוקה (seed, cleanup)
│   ├── tests/                # 28 בדיקות אוטומטיות
│   ├── app.js                # בניית אפליקציית Express (בלי listen)
│   └── server.js             # נקודת כניסה
│
└── frontend/                # אפליקציית React
    └── src/
        ├── api/              # מופע axios + interceptors
        ├── components/       # רכיבים משותפים
        ├── context/          # ניהול מצב אימות גלובלי
        ├── hooks/            # useAuth, useRecipeList
        ├── pages/            # עמודי האפליקציה
        └── utils/            # פענוח כתובות תמונה
```

> ההפרדה בין `app.js` ל-`server.js` מכוונת: היא מאפשרת לבדיקות להריץ את השרת בזיכרון, בלי לפתוח פורט ובלי להתחבר ל-Atlas.

## 🚀 התקנה והרצה

### דרישות מקדימות
- **Node.js** `20.19+` או `22.12+` (נדרש על ידי Vite 8)
- חשבון **MongoDB Atlas** (יש tier חינמי) או MongoDB מקומי
- *אופציונלי:* מפתח **Gemini API** ([חינם ב-Google AI Studio](https://aistudio.google.com/apikey)) — נדרש רק לפיצ'ר ה-AI

### שלב 1 — שכפול הפרויקט

```bash
git clone https://github.com/<username>/<repo>.git
cd <repo>
```

### שלב 2 — הגדרת השרת

```bash
cd backend
npm install
cp .env.example .env
```

פתח את `backend/.env` ומלא את הערכים (ראה [משתני סביבה](#-משתני-סביבה)).

**ליצירת `JWT_SECRET` חזק:**
```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

### שלב 3 — הגדרת הלקוח

```bash
cd ../frontend
npm install
cp .env.example .env
```

ברירת המחדל ב-`frontend/.env` מתאימה לפיתוח מקומי ולא דורשת שינוי:
```
VITE_API_URL=http://localhost:5000/api
```

### שלב 4 — הרצה

צריך **שני טרמינלים במקביל**:

```bash
# טרמינל 1 — שרת (פורט 5000)
cd backend
npm run dev
```

```bash
# טרמינל 2 — לקוח (פורט 5173)
cd frontend
npm run dev
```

פתח בדפדפן: **http://localhost:5173**

> 💡 **אופציונלי:** למילוי המסד ב-17 מתכונים לדוגמה, הירשם קודם דרך האתר (כדי שיהיה למי לשייך אותם), ואז הרץ `npm run seed` בתיקיית `backend`.

## 🔐 משתני סביבה

### `backend/.env`

| משתנה | חובה | תיאור |
|--------|:----:|--------|
| `MONGO_URI` | ✅ | מחרוזת חיבור ל-MongoDB. **חייבת לכלול שם מסד** אחרי ה-`/` |
| `JWT_SECRET` | ✅ | סוד לחתימת טוקנים. מומלץ 64 תווים אקראיים |
| `PORT` | ❌ | ברירת מחדל: `5000` |
| `GEMINI_API_KEY` | ❌ | בלעדיו נתיבי ה-AI מחזירים 503; שאר האתר עובד רגיל |
| `CLIENT_URL` | ❌ | כתובות מורשות ל-CORS, מופרדות בפסיק. ברירת מחדל: localhost |

> השרת מריץ ולידציה על משתני הסביבה **בעליה** (`config/env.js`) — אם חסר משתנה חובה, הוא נכשל מיד עם הודעה ברורה במקום להיכשל מאוחר יותר בשגיאת 500 מסתורית.

### `frontend/.env`

| משתנה | חובה | תיאור |
|--------|:----:|--------|
| `VITE_API_URL` | ✅ | כתובת הבסיס של ה-API. **חייבת להסתיים ב-`/api`** |

> ⚠️ Vite צורב את המשתנה לתוך ה-bundle **בזמן ה-build**. שינוי שלו מחייב build מחדש.

## 📡 תיעוד ה-API

כל הנתיבים תחת הקידומת `/api`.

### אימות — `/api/auth`

| Method | Endpoint | הרשאה | תיאור |
|--------|----------|--------|--------|
| `POST` | `/register` | ציבורי | הרשמה. מחזיר פרטי משתמש + טוקן |
| `POST` | `/login` | ציבורי | התחברות. מחזיר פרטי משתמש + טוקן |
| `GET` | `/me` | 🔒 מחובר | פרטי המשתמש המחובר |

### מתכונים — `/api/recipes`

| Method | Endpoint | הרשאה | תיאור |
|--------|----------|--------|--------|
| `GET` | `/` | ציבורי | רשימה. פרמטרים: `search`, `mine=true`, `page`, `limit` |
| `GET` | `/:id` | ציבורי | מתכון בודד |
| `POST` | `/` | 🔒 מחובר | יצירת מתכון |
| `PUT` | `/:id` | 🔒 בעלים/אדמין | עדכון מתכון |
| `DELETE` | `/:id` | 🔒 בעלים/אדמין | מחיקת מתכון |

### AI — `/api/recipes`

| Method | Endpoint | הרשאה | הגבלת קצב |
|--------|----------|--------|------------|
| `POST` | `/generate` | ציבורי | 20 / 15 דק' |
| `POST` | `/modify` | ציבורי | 20 / 15 דק' |
| `POST` | `/generate-image` | ציבורי | 15 / שעה |
| `POST` | `/save` | 🔒 מחובר | — |

**אימות:** נתיבים מוגנים דורשים כותרת `Authorization: Bearer <token>`.

**תגובת רשימה** מחזירה מבנה עם מטא-דאטה של עימוד:
```json
{ "recipes": [...], "page": 1, "pages": 3, "total": 28 }
```

## 🧪 בדיקות

```bash
cd backend
npm test           # הרצה חד-פעמית
npm run test:watch # מצב מעקב
```

**28 בדיקות** רצות מול **MongoDB אמיתי בזיכרון** (`mongodb-memory-server`) — בלי מוקים, בלי תלות ברשת, ובלי לגעת במסד האמיתי.

הכיסוי כולל בדיקות רגרסיה מפורשות לחורי אבטחה שנסגרו:
- ניסיונות **NoSQL injection** בשדות אימייל וסיסמה
- **מניעת התחזות** — התעלמות מ-`owner` שנשלח מהלקוח
- **בריחה מתווי regex** בחיפוש
- **הפרדת הרשאות** — משתמש אחר לא יכול לערוך/למחוק מתכון שאינו שלו

## 🔒 אבטחה

הפרויקט עבר סבב ביקורת קוד מתועד (`todo_and_fixes.md`) שבו נסגרו 35 ממצאים. עיקרי אמצעי ההגנה:

| אמצעי | מימוש |
|--------|--------|
| **הצפנת סיסמאות** | bcrypt (10 salt rounds) + `select: false` בסכמה |
| **NoSQL injection** | אימות `typeof === 'string'` לפני כל שאילתה עם קלט משתמש |
| **מניעת התחזות** | `owner` נלקח תמיד מהטוקן המאומת, לעולם לא מגוף הבקשה |
| **Mass assignment** | מחיקת `_id`/`owner`/`createdAt`/`__v` מה-body לפני עדכון |
| **Rate limiting** | לפי IP על נתיבי AI והתחברות |
| **כותרות אבטחה** | helmet (HSTS, noSniff, frameguard) |
| **CORS** | רשימת דומיינים מותרת בלבד, לא פתוח לכולם |
| **חשיפת מידע** | הודעת התחברות כללית שלא מסגירה אילו אימיילים רשומים |
